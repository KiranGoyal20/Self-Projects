# Admin Panel

React admin console built with **Chakra UI**, React Router, and mock APIs.

## Features

- Sidebar: Providers, Consumers, Admins, Inbox
- Search forms + results tables
- Create modals (consumer invite vs direct create)
- Admin Role dropdown (CSR, Family Admin, Provider Admin, Exchange Admin, Ops Admin)
- Inbox notifications

## Run

```bash
cd admin-panel
npm install
npm run dev
```

## Stack

- Vite + React + TypeScript
- Chakra UI v3
- react-icons
- React Router
