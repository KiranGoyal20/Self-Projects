# Portfolio

A gallery of live products. Each card is a **widget** that looks like the app — click it to open the deployed site.

## Apps

| Widget | Live URL |
| --- | --- |
| Analytics Dashboard | https://analytics-dashboard20.netlify.app/ |
| Mood Companion | https://mood-companion.netlify.app/ |
| Morrow | https://meeting-calender-app.netlify.app/ |
| Next.Quest | https://nextjs-quest.netlify.app/ |
| Benefits Enrollment | https://onboarding-flow-app.netlify.app/ |
| Exchange Admin | https://exchange-admin-panel.netlify.app/ |

To add or change a link, edit `src/data/projects.ts`.

## Run

```bash
cd portfolio
npm install
npm run dev
```

## Build / deploy

```bash
npm run build
```

`netlify.toml` publishes `dist`. Point Netlify at the `portfolio` folder, or drag the `dist` output into a new site.
